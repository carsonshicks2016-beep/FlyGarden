# Published olfactory-dynamics reference: prospective reproduction

Selected reference: Liu, Li, Tang, Qin and Tu (2021), *Short-Term Plasticity Regulates Both Divisive Normalization and Adaptive Responses in Drosophila Olfactory System*, DOI10.3389/fncom.2021.730431. Official XML equations1–5, steady-state equation12 and ramp asymptote equation15, figures4–5. Article is CC BY. Pin retrieved XML/HTML/figure hashes; no author numerical simulator or raw Figure4/5 model time series is linked in the article. Independent equation reconstruction and published-figure digitization are the supported reproduction levels.

Reasons: explicit release facilitation/depletion, reversible recovery and presynaptic inhibition; published dynamic PN predictions. The 2024 PQN alternative has code/data and an MIT license, but its documented reference workflow requires a Cmod A7 FPGA/Vivado. Preserve its pinned source for later study; do not claim hardware reproduction.

Use published Figure4/5 values: U=.24; omegaEE=75nS; omegaIE=21nS; tauE=.055s; rho=.008s; tauP=.3s; tauF=.05s; tauD=.1s; conversion k=5Hz/nS (explicit Figure5 caption). Mean-field equations use rate variables; apply conversion to both synaptic-strength coefficients, effective omegaEE=375 and omegaIE=105. The article does not spell out this unit conversion in equations1–5, so retain that implementation convention explicitly. A preliminary K=400 ramp feasibility check tested fixed LN-conversion factors1 and5 with the published PN conversion5: only applying both gave the published approximately180Hz peak and95Hz plateau. This is not a fitted parameter. The subsequent curve validation below was registered before those curve measurements.

Initial state PN=LN=uMinus=0; p=x=1, as stated in Methods. State order PN,LN,p,x,uMinus. uPlus=uMinus+U*(1-uMinus).

Additional engineered step/pulse/repeated-pulse/restart reference checks: finite/bounded dimensionless state, response decline during held input and recovery after removal; p/x/u resources recover. These are equation sanity checks, not published figure reproduction or learned preference. Register input windows in run script. Carry all five state variables across an interrupted numerical run; compare uninterrupted continuation within numerical tolerance.

Scope: isolated published mean-field reference, not a reduced replacement for the full connectome, not spiking/body control, navigation or learning acceptance. Do not copy DL5/VM7 or generic Figure4 parameters to DM1/DM2 and call them validated physiology. Base anatomical weights remain unchanged in the application. Short-term release/resource state is distinct from the long-term KC–MBON learning mechanism.

Integration boundary: the published model is feedforward; it does not contain the full brain's recurrent loops. In our recorded full network, stimulated DM1 ORNs are already quiet while downstream activity persists. ORN-to-PN adaptation alone therefore cannot be assumed to extinguish the autonomous downstream state. A full-network candidate needs exact annotation/compartment mapping, a justified treatment of recurrent drive, new model identity, checkpoints for transient resource state and unchanged held-out behavioral gates. No full-network alteration in steps1–2.
